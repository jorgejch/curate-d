# Tasks

The streams are laid out in design.md D9. Group 0 (S0) runs first, on the change branch
`tie-placement-to-account-and-location`, cut from `origin/dev`. Once 0.9 passes, groups 1 to
5 start at once, each as an Opus sub-agent on its own worktree branched from S0's tip,
touching only the files its group lists; no task waits on another group. Merge the streams
back into the change branch in any order. Group 6 runs on the merged branch.

The reference implementation is PR #24's diff, adapted to design.md:
`gh pr diff 24 --repo jorgejch/curate-d > /tmp/pr24.diff` once, then read the hunk for the
file at hand (its branch is deleted, so the diff is the only copy). Integration tests need
`make test-stack` once per worktree before their first run. Unit commands use
`uv run pytest -n auto <paths> --no-cov`; integration commands use
`uv run pytest <files> --no-cov -m integration`. Comparisons in new tests use separately
built inputs, never an expression against itself (SonarCloud S5863).
