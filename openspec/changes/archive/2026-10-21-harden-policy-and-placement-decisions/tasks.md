# Tasks

The streams are laid out in design.md D13. Group 0 (S0) runs first, on the change branch
`harden-policy-and-placement-decisions`, cut from `origin/dev`. Once 0.8 passes, groups 1 to
7 start at once. Each runs on its own worktree, branched from S0's tip, and touches only the
files its group lists. Exactly one task crosses streams: 5.5 waits on 3.2. Merge the streams
back into the change branch in any order, except that 5 merges with or after 3. Group 8
runs on the merged branch.

Use each PR's diff as the reference implementation, adapted to design.md:
`git diff 4ad75ee pr/<n>`. Fetch a PR head with
`git fetch origin pull/<n>/head:refs/remotes/pr/<n>`. Integration tests need
`make test-stack` once per worktree before their first run. Unit commands use
`uv run pytest -n auto <paths> --no-cov`; integration commands use
`uv run pytest <files> --no-cov -m integration`.
